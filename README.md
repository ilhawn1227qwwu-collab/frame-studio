# FRAME STUDIO — YouTube · TikTok · Instagram · X(트위터) 미디어 추출 웹사이트

유튜브 영상 링크를 입력하고 **MP4 영상** 또는 **MP3 오디오**로 저장할 수 있는 개인용 웹사이트입니다. 휴대폰에서 쓸 수 있는 클라우드 배포 구성도 포함합니다. 영상 정보/썸네일 확인, 원본에서 실제 제공하는 화질(최대 1080p), 오디오 비트레이트 선택, 구간 자르기, 진행률 및 다운로드 버튼이 포함돼 있습니다.

> **이용 범위:** 본인이 저작권을 보유했거나 권리자에게 다운로드 허락을 받은 콘텐츠 등 합법적이고 YouTube 약관상 허용되는 경우에만 사용하세요. 다른 사람의 영상을 무단으로 다운로드·배포해서는 안 됩니다. DRM, 연령/로그인 인증, 비공개 영상, 재생목록, 라이브 추출 기능은 제공하지 않습니다.

## X(트위터) 공개 동영상 지원 (v1.8.0)

- **X/Twitter 공개 영상·GIF:** `x.com` 및 `twitter.com`의 개별 게시물 링크를 입력하면 MP4로 저장하고, 오디오 트랙이 있는 영상은 MP3도 추출할 수 있습니다.
- **처리 경로:** FxTwitter의 공개 게시물 API를 통해 영상 메타데이터와 공개 MP4 주소를 확인하고 `video.twimg.com` 원본 파일을 FRAME STUDIO 서버에서 다운로드합니다. FxTwitter가 막히면 기존 `yt-dlp`를 통한 직접 추출을 시도합니다. 외부 API에 게시물 번호가 전달될 수 있으며 계정 비밀번호와 로그인 쿠키는 사용하지 않습니다.
- **지원 제한:** 단일 공개 게시물의 첫 번째 영상만 다운로드합니다. 비공개·삭제·로그인 필요 콘텐츠, 사진만 있는 게시물, 외부 임베드 영상 및 다중 영상 일괄 추출은 지원하지 않습니다. 실제 X 서버의 접근 차단 또는 FxTwitter 장애로 실패할 수 있습니다.
- **검증 범위:** 링크 형식·외부 호스트 검증·응답 처리·MP4/MP3 변환 경로를 외부 네트워크 요청 없는 자동 테스트로 검증합니다. 공개 X 실제 게시물의 Render 다운로드 성공은 별도 확인이 필요합니다.

## TikTok · Instagram 확장 (v1.7.1)

- **TikTok 공개 영상:** 공개 TikTok 영상을 추출합니다. TikTok의 직접 연결이 막힐 경우 **TikWM 처리 서버로 영상 불러오기**를 선택하면 FRAME STUDIO 안에서 MP4/MP3를 저장할 수 있습니다. 2026-11-04 Render에서 실제 영상 다운로드·MP4 파일 생성을 확인했습니다.
- **Instagram 공개 릴스·일반 동영상:** Instagram 게시물·릴스 주소를 입력하면 공개 미리보기 서비스 **vxInstagram**에서 먼저 원본을 확인하고, 실패할 경우 **Instagramfix · ogInstagram · Kirkstagram** 등 독립적인 공개 미리보기 서비스를 순서대로 시도합니다. 어느 경우에도 파일은 **FRAME STUDIO 안에서 직접 MP4 또는 MP3**로 저장합니다. 2026-11-04 Render에서 약 45초 릴스와 일반 영상뿐 아니라 **약 80초 릴스의 대체 서버 MP4 저장**까지 실증했습니다.
- **Instagram 사진·캐러셀:** 사진 한 장은 JPG/PNG/WebP 등 소스가 제공하는 이미지 형식으로 저장합니다. 사진 여러 장 또는 영상이 섞인 캐러셀은 하나의 ZIP 파일로 저장합니다. 2026-11-04 Render에서 **사진 5장짜리 게시물을 실제 다운로드해 ZIP으로 생성**했습니다.
- **Instagram 공유 링크:** 앱에서 복사된 `/share/reel/`과 `/share/p/` 링크는 실제 게시물 주소로 해석하려고 시도합니다. 일부 공유 링크는 로그인·리다이렉션 제한 때문에 열리지 않을 수 있습니다.
- **Instagram 제한:** 공개 게시물만 지원합니다. 원본 동영상의 재생 길이는 실제 파일을 받은 후 확인하므로 vxInstagram 경로에서는 **구간 자르기를 지원하지 않습니다**. 로그인 필요·비공개·삭제·지역 제한 콘텐츠는 지원되지 않습니다. vxInstagram 미리보기 경로들은 독립 서비스로, 게시물 주소가 실제 이용되는 서비스에 전달됩니다. 서비스 운영자의 가용성·요청 제한에 영향을 받으며, 접속 암호나 로그인 쿠키는 공유하지 않습니다.
- **공통 범위:** 권리를 보유하거나 허가받은 단일 공개 게시물만 처리합니다. 스토리, 비공개 계정, DM, 프로필 전체 수집, 계정 로그인 우회는 지원하지 않습니다.

## 스마트폰에서 주소로 사용하기

스마트폰에는 아무것도 설치하지 않습니다. 외부 서버에 배포해야 접속할 수 있으며, 방법은 **[DEPLOY_MOBILE.md](DEPLOY_MOBILE.md)**에서 확인하세요. **Dockerfile / railway.json / render.yaml** 포함. 배포하지 않은 상태에서는 공용 URL이 없습니다.

## 온라인 Render 서버 사용법 (일반 영상 및 Shorts)

실제 모바일 사이트: https://frame-studio-9ho7.onrender.com

1. 유튜브 주소를 입력합니다. 쇼츠가 아닌 **일반 영상도 지원**합니다.
2. 기본 **영상 불러오기**가 유튜브의 클라우드 IP 차단으로 실패하면, 바로 보이는 **외부 서버로 바로 불러오기**를 선택합니다.
3. 외부 공개 Invidious 서버로 영상 **ID만 전달**한 뒤, MP4/MP3 및 화질·구간을 선택합니다.
4. 추출이 끝나면 **완성된 파일 저장하기**로 저장합니다.

**길이 제한:** 배포된 사이트는 최대 **2시간(120분)** 길이의 영상까지 시도하도록 설정했습니다. 이전의 외부 경로 3분 제한은 제거했습니다. **이는 성공을 보장하는 길이가 아닙니다.** 무료 Render 환경에서 외부 경로는 최대 **1080p(원본 제공 시)**, 다운로드한 영상/음성 원본 합계 약 **220MiB** 이내를 목표로 제한합니다. 큰 파일은 화질을 낮춰도 제한을 초과할 수 있으며, 서버 CPU·네트워크와 외부 공개 서버의 자체 제한이 적용됩니다. 외부 서버를 과도하게 사용하지 마세요. 라이브, 유료, 로그인/연령 제한 영상은 지원하지 않습니다.


**음질 선택:** MP3는 128/192/320kbps 출력 인코딩이며 원본보다 음질이 개선되지는 않습니다. 외부 공개 서버에서 AAC 또는 Opus 스트림이 제공되면 **M4A 원본**·**Opus 원본** 형식으로 추가 압축 없이 저장할 수 있습니다. 고화질 MP4는 원본 H.264/AAC 형식일 경우 재인코딩 없이 저장합니다. Render 무료 서버 메모리 때문에 1080p 구간 추출은 **키프레임 기준**이며 시작/종료 지점에서 약간의 오차가 있을 수 있습니다.

## 1. PC에서 직접 실행하려면

1. **Python 3.11 이상**: https://www.python.org/downloads/ (Windows에서는 설치 중 `Add python.exe to PATH` 체크)
2. **FFmpeg 및 ffprobe**: https://ffmpeg.org/download.html
   - Windows: `winget install Gyan.FFmpeg` 로 설치하거나 FFmpeg 바이너리를 PATH에 추가하세요.
   - macOS: `brew install ffmpeg`
   - Ubuntu/Debian: `sudo apt install ffmpeg`
3. **Deno 2.3 이상**: https://docs.deno.com/runtime/getting_started/installation/ (최신 yt-dlp의 YouTube JavaScript 처리에 필요)
   - Node.js 22+도 대체 사용 가능하며 서버가 자동 감지합니다.

설치 확인용 터미널 명령: `python --version` / `ffmpeg -version` / `ffprobe -version` / `deno --version`

## 2. 실행하기

### Windows
1. 이 프로젝트 압축 파일을 풀어 폴더를 엽니다.
2. **`start_windows.bat`** 더블 클릭.
3. 최초 1회는 Python 패키지를 설치합니다. 브라우저에서 `http://127.0.0.1:8000` 을 여세요.
4. 종료 시 명령 프롬프트를 닫으세요.

### macOS / Linux
```bash
cd frame-studio
./start_mac_linux.sh
```
브라우저에서 **http://127.0.0.1:8000** 접속. Ctrl+C로 종료합니다.

### 수동 실행
```bash
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python server.py
```

## 3. 이용 방법

1. 공개된 YouTube 영상 URL을 붙여넣고 **영상 불러오기** 클릭.
2. 제목/채널/썸네일/길이를 확인합니다.
3. MP4, MP3 또는 외부 경로에서 제공하는 M4A·Opus 원본 오디오를 선택하고 화질을 정합니다.
4. 일부만 필요하면 **구간 자르기**를 켜고 시작/종료 시간을 입력합니다.
5. 다운로드 권한을 확인한 뒤 **파일 추출하기** 클릭.
6. 완료 후 **완성된 파일 저장하기**를 누릅니다.

## 구현 방식

- 프런트엔드: HTML/CSS/JavaScript (모바일 화면 대응)
- API 서버: FastAPI / Uvicorn
- 정보 추출/미디어 다운로드: yt-dlp + `yt-dlp-ejs` (`yt-dlp[default]` 패키지 설치)
- 형식 변환/구간 자르기: FFmpeg
- 임시 파일: OS 임시 폴더의 `frame-studio-jobs/`, 완료 후 1시간 지나면 다음 API 요청 시 정리
- 기본 실행: `127.0.0.1:8000`으로 PC 로컬에서만 접속. `FRAME_PUBLIC_MODE=1`을 설정하고 웹 호스팅에 올리면 외부 HTTPS 접속 가능. 외부 공개 시 `FRAME_SITE_PASSWORD` 필수(12자 이상).
- 동시 작업 최대 2개, 영상 길이 최대 2시간, 원본 다운로드 파일 크기 최대 1GB, 다운로드 주소는 랜덤 토큰 사용.

## 문제 해결

- **추출이 안 될 때**: `pip install -U "yt-dlp[default]"` 를 통해 업데이트한 뒤 재실행합니다. YouTube가 제공하는 영상 형식이나 접근 정책은 수시로 변경되어 모든 영상의 성공이 보장되지는 않습니다.
- **Deno가 없다고 뜰 때**: Deno 설치 후 새 터미널에서 다시 실행하세요. Node.js 22+도 대체 가능합니다.
- **FFmpeg가 없다고 뜰 때**: `ffmpeg -version`, `ffprobe -version` 이 동작하는지 확인합니다.
- **구간 추출이 느릴 때**: 정확한 구간 맞춤을 위해 동영상 재인코딩을 수행합니다.
- **1080p가 안 뜰 때**: 원본에 해당 해상도가 없는 경우 선택할 수 없습니다.
- **추출한 영상이 화질이 떨어질 때**: MP4 변환이 필요한 코덱은 H.264로 재인코딩됩니다.
- **브라우저 주소가 열리지 않을 때**: 터미널에 오류가 없는지 확인하고, 직접 `http://127.0.0.1:8000`에 접속해 보세요.

## 주의: 공개 인터넷 배포

비밀번호 보호, 요청 횟수 제한, 원본/출력 제한을 추가했지만 **사적인 개인 웹사이트**를 전제로 합니다. 불특정 다수를 위한 서비스로 운영하려면 더 강력한 인증, 여러 인스턴스에서의 작업 상태 저장, 비용 제한, 로깅/모니터링, 남용 방지 등 추가 설계가 필요합니다. 호스팅 서버에서 YouTube 연결이 차단되거나 요청이 실패할 수 있습니다.
