    ▤ Kali Security Training — Notes

    첫 수업 · 무선 네트워크 보안

    여기서 사용하는 명령은 실제 Linux/Kali 도구의 문법을 참고했지만, 실행되는 것은 JavaScript 모형입니다. 암호 목록·캡처 파일도 가상의 학습 데이터예요.

    1. 운영체제와 네트워크

    whoami, pwd, ls, ip a는 리눅스에서 널리 쓰는 명령입니다. nmcli dev wifi list는 NetworkManager의 주변 네트워크 목록 기능입니다. 이 앱의 목록은 실제 주변 네트워크가 아닙니다.

    2. 모니터 모드와 AP 관찰

    airmon-ng는 모니터 모드 설정을 돕고, airodump-ng는 무선 트래픽을 관찰하는 데 쓰입니다. 이 실습에서는 장치 제어와 캡처가 전혀 일어나지 않고, 가상 어댑터 상태와 학습용 AP 자료만 바뀝니다.

    3. WPA2 핸드셰이크와 사전 대입 위험

    WPA2-Personal의 4-way handshake에 비밀번호 평문이 들어 있는 것은 아닙니다. 약한 비밀번호는 캡처한 인증 교환을 이용한 오프라인 후보 검사에 취약할 수 있습니다. 이 실습의 가짜 캡처 파일은 이미 허가된 클라이언트의 정상 연결을 재현하며, 패킷 해독 대신 미리 정한 후보 8개와 문자열을 비교합니다.

    4. 연결 복구와 보안 개선

    모니터 모드를 종료한 뒤 nmcli를 사용해 가상 연결을 수행합니다. 마지막에는 공유기 설정 화면에서 WPA3-SAE와 긴 고유 암호를 선택합니다. 실제 WPA3는 모든 종류의 공격을 막는 기술은 아닙니다.

    도움 명령

    help, history, clear, status, man nmcli, cat README.txt. 마지막 lab-verify는 이 프로그램에서만 쓰는 교육용 전용 명령이며 실제 Kali 명령이 아닙니다.
